# Hostel Electricity Billing & Analytics

A cloud-based hostel electricity billing and tenant notification system built using Python, Streamlit, SQL, and cloud technologies.

## Project Overview

This project aims to automate the manual process of calculating hostel electricity bills based on meter readings, room occupancy, and tenant stay duration.

The application will allow the hostel warden to enter electricity meter readings and tenant information through a Streamlit web application. The system will calculate individual electricity charges, store historical billing data, provide analytics, and automate bill notifications to tenants.
